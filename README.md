# Candy House Adventure

Play: https://larinastudy01-lab.github.io/unfinished-tales-play/

Public playable build with keyboard and touch controls. This repository contains only the generated game and the artwork required to play it.

Latest update: dark translucent RPG dialogue panels, gold nameplates and character portraits. Click the dialogue panel or press Enter to read the next line; SKIP jumps to the end of the current story group and saves normal progress. Previous game features and original artwork are retained.

Release source: d653f2015c8eff4c67612311717947d79de1c100.

Validated before publishing: 38 core tests covering every line of all seven SKIP story groups, four browser checks including desktop and portrait/landscape phones, TypeScript checks, and a production build. Build provenance and file hashes are recorded in release.json.
