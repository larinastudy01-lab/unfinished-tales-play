# Candy House Adventure

Play: https://larinastudy01-lab.github.io/unfinished-tales-play/

Public playable build with keyboard and touch controls. This repository contains only the generated game and the artwork required to play it.

Latest features: golden start-button glow, berry-purple character setup, and a pictorial tutorial floating above the third-floor starting scene. The tutorial automatically starts play after fifteen seconds, supports early start, and pauses its countdown with the game.

Release source: fd4db678cad77ee840d62a83c487b1e18fef1d83.

Validated before publishing: 36 core tests, 6 browser tests across desktop and portrait/landscape phones, 3 final layout checks, TypeScript checks, and a production build. Build provenance and file hashes are recorded in release.json.
