## 0.22.0：全場景載入與控制列清理

## 0.21.0：首頁載入效能

首頁選角、暱稱及原 start_icon 使用獨立 HTML／CSS，不再等待 Phaser、Canvas 或整批場景圖。引擎在背景初始化，接手時保留同一個輸入框、選角、焦點及圖片；選角與輸入時預載開場及三樓，漫畫逐張載入並預載下一張。

背景依螢幕選用 1672／1280／960px 高畫質 WebP，分別為 393,168／300,664／222,784 bytes。四張必要圖共 617,076／524,572／446,692 bytes，舊版四圖為 5,167,418 bytes。首頁不等待箭頭及道具；圖片共用快取、8 秒讀取期限、2.5 秒解碼期限及一次重試，失敗不鎖死首頁。

第 1～55 類正式美術、157 個原圖來源、316 張前版衍生圖、全部關卡、物理、解謎及音訊保留。產品來源 `6e50a5e87d741c24141296ad6f4f67ea3049b0cd`，1,471 個來源 Git blob 核對相同。TypeScript、素材檢查、315／315 模型測試與 20／20 Chrome 回歸通過；iPad 與手機為 Chrome 尺寸／觸控模擬。

Network／Resource Timing、獨立 Performance trace、真實磁碟快取、原生 Element Timing、場景等待及記憶體比較見來源專案 `STARTUP_PERFORMANCE.md`。實際圖片繪製與可操作時間分別記錄，不以 rAF 或顯式 decode 等待取代真正繪製／解碼數據。`release.json` 保存精確產品來源與全部建置雜湊。
