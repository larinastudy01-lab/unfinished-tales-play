# Candy House Adventure

Play: https://larinastudy01-lab.github.io/unfinished-tales-play/

Public playable build with keyboard and touch controls. This repository contains only the generated game and the artwork required to play it.

Latest features: sixteen lethal second-floor obstacles, moving ghost collisions, pictorial tutorials before each runner level, clean third-floor gameplay, full-screen comics with floating subtitles, and the supplied game icon.

Release source: de8a2bcb05d0093cf272429d2869ce3a232caa02.

Validated before publishing: 34 core tests, complete keyboard and touch escape routes, responsive tutorial checks, TypeScript checks, and a production build. Build provenance and file hashes are recorded in `release.json`.
