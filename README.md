# Candy House Adventure - playable build

Play: https://larinastudy01-lab.github.io/unfinished-tales-play/

Version 0.8.1 removes the overhead third-floor timer lamps while retaining the internal 60-second limit. Version 0.8.0 adds a second continuous cooperation relay to the third floor. First, land on the upper plate to open the companion's cookie gate; the companion extends the player's wafer shortcut. Later, the companion takes the upper route and raises a lollipop gate for the player below. Jump onto the side plate to extend a wafer across the companion's gap. Timely help lets the companion cross and rejoin sooner; missed or late help sends the companion along a visible downhill detour. The normal player route always remains playable within the original 60-second limit. The selected sibling remains the only controlled character. The original knowledge chase, first-floor puzzles and ending remain.

Keyboard: A/D or arrows move; Space/W/Up jump (tap low, hold high); Q uses a collected gummy. Standard mapped PS-style gamepad: D-pad/left stick move, cross jumps, square uses a gummy, Options pauses. No new interaction key is needed for either relay. First-floor and knowledge-answer controls remain as explained before play.
